# AMLens user guide

Welcome. This guide is for analysts and investigators who use AMLens to review transaction alerts. You do not need any technical knowledge to follow it.

AMLens helps you work through suspicious-looking payments. You upload a file of transactions, AMLens flags the ones that need a closer look (called [alerts](glossary.md)), an AI assistant drafts an evidence-linked investigation report, and **you** record the final decision. Every step is written to an [audit trail](glossary.md).

!!! note "The AI drafts. A person decides."
    AMLens never closes, approves or escalates a case by itself. The AI report is a draft to help you. Only a signed-in human investigator can record a decision.
